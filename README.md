# taskmonad

A monadic task execution and scheduling framework with Qt bridge support.

## Project Structure

```text
taskmonad/
├── pyproject.toml
├── README.md
├── taskmonad/

│   ├── qt_bridge.py
│   └── serialization.py
└── examples/
    ├── pipeline_demo.py
    └── pyqt_app.py
```

## Installation
